# 🐇 Palindrome Checker 🐇

This is a simple palindrome checker project, developed as part of the **JavaScript Algorithms and Data Structures** course from [freeCodeCamp](https://www.freecodecamp.org/). It was created to practice core concepts of **HTML**, **CSS**, and **JavaScript**.

###  Objective

The project checks whether a given word or sentence is a **palindrome** — meaning it reads the same forwards and backwards, ignoring punctuation, spaces, and capitalization.

###  Technologies Used

- HTML5
- CSS3 (with media queries for responsiveness)
- JavaScript
- Figma for prototype 

### Features

- Automatically checks if the input is a palindrome.
- Provides visual feedback with color and image changes.
- **Responsive** interface: adapts to different screen sizes.
- **Accessible**: screen-reader-friendly, using proper semantics and `aria-*` attributes.
